# Підготовка до захисту лабораторної №1

## Короткий виступ (приблизно 5 хвилин)

Мета роботи — навчитися використовувати генератори та ітератори Python
для читання великого корпусу текстів без завантаження всіх документів
одночасно в оперативну пам'ять.

Я створив Python-проєкт `findex` зі структурою `src/`, використовуючи
`uv`. Корпусом для майбутньої пошукової системи обрав офіційну
документацію Python. Для офлайн-демонстрації створюється набір із
1000 синтетичних ІТ-нотаток.

Перша функція — `iter_documents()`. Вона обходить файли через `pathlib`
і повертає по одному документу за допомогою `yield`.
Друга — `tokenize()`. Вона нормалізує Unicode, застосовує `casefold`
і видає токени через `re.finditer`, не накопичуючи їх у списку.

Модуль статистики рахує документи, токени, розмір словника і топ-50
найчастіших термінів за один прохід. Для порівняння я реалізував
жадібну версію, яка зберігає всі документи й токени у списках.
За допомогою `tracemalloc` вимірюється пікова пам'ять, а
`time.perf_counter()` — час виконання.

Спочатку я перевірив реалізацію на 1000 синтетичних ІТ-нотаток,
а потім завантажив 514 справжніх документів офіційної документації
Python 3.13. У реальному корпусі програма знайшла 1 921 193 токени
та 41 255 унікальних термінів. Під час вимірювання на Windows із
Python 3.13.18 лінива версія використала 33.369 MiB за 14.917 с,
а жадібна — 125.631 MiB за 7.418 с. Генератори скоротили
пікові Python-алокації приблизно у 3.76 раза, хоча працювали повільніше.
Програма підтвердила ідентичність результатів обох алгоритмів.
17 автоматичних тестів пройшли, Ruff не знайшов помилок.
Час і пам'ять залежать від середовища запуску.

## Запитання викладача

**1. Чим відрізняється iterable від iterator?**
Iterable — об'єкт, з якого можна отримати ітератор через `iter()`.
Iterator має `__next__()`, повертає елементи по одному і після
вичерпання сигналізує `StopIteration`.

**2. Що робить yield?**
Призупиняє виконання генератора і повертає наступне значення, зберігаючи
локальний стан до наступного виклику.

**3. Чому генератор економить пам'ять?**
Він не формує список усіх результатів: створює наступний елемент
лише тоді, коли той потрібен.

**4. Чому використовуємо casefold(), а не lower()?**
`casefold()` виконує ширше Unicode-приведення, наприклад
німецьке `Straße` і `STRASSE` стають однаковими.

**5. Навіщо NFC?**
Два візуально однакові слова можуть складатися з різних Unicode-кодів.
NFC приводить їх до канонічно узгодженого представлення.

**6. Чому lazy не завжди швидший?**
Генератори мають накладні витрати на ітерацію; економія пам'яті не
гарантує переваги за часом.

**7. Що саме вимірює tracemalloc?**
Пікові алокації пам'яті, що відстежуються механізмом Python. Це
не показник загальної пам'яті процесу та не обсяг використаної RAM.
